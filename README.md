# mc-compass
This is a Raspberry PI Pico based project to build a Minecraft compass


## Parts
### Hardware
- Raspberry Pi Pico W (pico_w)
- 104 WS2812B Leds (96 LED/m)

### Casing
Onshape was used for modeling the casing. My model can be found here on [Onshape](https://cad.onshape.com/documents/2954096eab48da43fce2e3a5/w/52b27194366e5974540d06c7/e/4bc3bc189969e967a184079d?renderMode=0&uiState=69536dbbf53494d960e3e1fb). This model is parametrised so it can be reused with different LED densities. Thicknesses can also be tuned.

Parts were printed on an Anycubic i3 Mega S in clear PLA, and black PLA.

Front plate is a two color print, first clear PLA for the face of the compass, then black PLA for the light guides.
